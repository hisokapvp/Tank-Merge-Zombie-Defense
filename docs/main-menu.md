# Главное меню (big menu)

## Когда показывается

- При открытии страницы сначала показывается отдельный full-screen overlay `#bigMenuOverlay`.
- До выбора действия из big menu игра не запускает `boot()` и не запускает `loop()`.

## Кнопки (порядок фиксированный)

1. `#bigMenuNew` — **Новая игра**
   - Запускает boot.
   - После boot сразу выполняет reset в режим новой игры.
   - In-session меню закрывается (`setMenuOpen(false)`), игрок сразу попадает в сессию.
2. `#bigMenuLoad` — **Загрузить**
   - Запускает boot.
   - Загружает прогресс из `localStorage['progress']` через обычный runtime-пайплайн загрузки.
   - In-session меню закрывается (`setMenuOpen(false)`), игрок сразу попадает в сессию.
3. `#bigMenuSound` — **Звук**
   - Открывает простую вложенную панель со слайдерами SFX/Music.
4. `#bigMenuLanguage` — **Язык**
   - Открывает простую вложенную панель выбора `РУ/EN`.
5. `#bigMenuFeedback` — **Обратная связь**
   - Пробует программно кликнуть `#feedbackBtn` (если существует), иначе вызывает `Game.FeedbackWidget.open()`.
6. `#bigMenuDevs` — **Devs**
   - Открывает простую dev-панель внутри big menu.

## Логика `Загрузить`

- Проверка делается по `getSavedProgress()` (источник — `localStorage['progress']`/Storage API).
- Если сохранения нет:
  - `#bigMenuLoad` переводится в `disabled`;
  - показывается подсказка с текстом: **«Нет сохранения»**;
  - у кнопки выставляется `title="Нет сохранения"`.
- Если сохранение есть:
  - кнопка `#bigMenuLoad` активна;
  - подсказка скрыта.

## Отличие от in-session меню

- Big menu — стартовый экран перед первым запуском boot/loop.
- In-session меню (`#menuOverlay`, gear/ESC) — внутриигровое меню паузы, остаётся в проекте и работает как раньше.
