# Fence layout: corner/side stык

Документ описывает, как устраняется щель между corner и side сегментами забора и как вручную подстроить стык через `cornerInsetPx`.

## Где настраивать

- Конфиг: `assets/fence.json`
- Геометрия: `src/render/fenceLayout.js`

## Параметр `cornerInsetPx`

- Тип: `float`
- Default: `0`
- Отрицательное значение: допустимо
- Назначение: ручная signed-подстройка угловых (`corner*`) сегментов **после** базового математического стыка.

Практика:

- `cornerInsetPx = 0` — базовый корректный стык по геометрии спрайтов.
- `cornerInsetPx < 0` — corner сильнее заходит в side (контролируемое перекрытие).
- `cornerInsetPx > 0` — corner уходит от side (может проявиться щель).

## Принцип расчёта стыка

Стык corner↔side считается по фактическим размерам спрайтов после применения:

- `frame.scale`
- `rotation` (`rotation -> rotationDeg -> 0`)
- `anchor`
- runtime-масштаба fence (`fenceWidth`)

То есть раскладка опирается на реальные bounds, а не на фиксированные inset-константы.

Для каждой стороны (top/right/bottom/left):

1. Берутся реальные границы соседних corner-спрайтов в направлении стороны.
2. Между этими границами раскладываются side-сегменты.
3. `holeAabb` каждого сегмента считается из тех же bounds, что используются для отрисовки.

Это синхронизирует визуал и hit-геометрию (без «бьём в воздух»).

## Автопроверка щели (`Fence gap`)

После построения layout вычисляется максимальная щель в стыках corner↔side.

- Порог: `0.5px`
- Условие warning: `gap > 0.5`
- Формат (ровно): `console.warn("Fence gap", valuePx)`

Где `valuePx` — максимальная вычисленная щель в используемых координатах layout.

## Как убрать щель на практике

1. Оставить `cornerInsetPx: 0` и проверить визуал.
2. Если щель видна из-за конкретного арта/pivot, уменьшать `cornerInsetPx` в отрицательную сторону небольшими шагами (например, `-0.5`, `-1`, `-1.5`).
3. Остановиться на значении, где щель исчезла, но нет заметного артефактного пересечения.
4. Проверить консоль: при корректной стыковке предупреждение `Fence gap` не появляется.
