# Achievements UI: collapse список

## Цель

- По умолчанию в модалке достижений показываются только названия.
- Описание каждого достижения раскрывается отдельной кнопкой `+`.
- Одновременно открыто только одно достижение (`single-open`).

## Структура строки

Каждое достижение рендерится как:

- `header-row`: `title` + кнопка раскрытия `+` (справа).
- `description-row`: прогресс/статус/награда под заголовком.

Поля:

- `title`: локализованный заголовок достижения.
- `progress`: `achievementProgress`.
- `status`: `achievementStatusDone`/`achievementStatusTodo`.
- `reward`: `achievementReward`.

## Логика single-open

- В UI-контроллере хранится `openAchievementId`.
- Клик по `+` на уже открытой строке закрывает её (`openAchievementId = null`).
- Клик по `+` на другой строке закрывает предыдущую и открывает новую.
- Обработчик клика один на контейнере списка (event delegation), без слушателя на каждую строку.

## A11y / семантика

- Кнопка раскрытия: `type="button"`.
- Кнопка получает `aria-expanded="true/false"`.
- Кнопка связывается с описанием через `aria-controls="achievementDesc_<id>"`.
- Блок описания имеет `id="achievementDesc_<id>"` и обновляет `aria-hidden`.
- Клавиатура: `Enter/Space` работает нативно, так как это `<button>`.

## Поведение кнопки

- Символ кнопки остаётся `+` в открытом и закрытом состояниях.
