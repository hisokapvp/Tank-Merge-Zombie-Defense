# PLAYBOOK: Добавить UI-виджет

## Когда использовать

Нужно добавить новую кнопку/панель/индикатор в HUD или модалку.

## Шаги

1. Добавь разметку в `index.html`.
2. Добавь стили в `style.css` (используя существующие переменные `:root`).
3. Добавь логику в `src/ui/<widget>.js` (предпочтительно) или в `boot()` если это маленькая привязка.
4. Подключи скрипт в `index.html` перед `game.js`.
5. Если это модалка — подключи `Game.A11y` (`openModal/closeModal`).
6. Добавь i18n ключи в `src/i18n/ru.json` и `src/i18n/en.json`.

## Какие файлы обычно править

- `index.html`
- `style.css`
- `src/ui/*.js`
- `src/i18n/ru.json`
- `src/i18n/en.json`

## Проверки

- Открытие/закрытие UI, проверка клика и keyboard навигации.
- Переключение RU/EN.
- При модалке: Escape закрывает, Tab trapped.

## Типовые ловушки

- Пропущен i18n ключ в одной из локалей.
- Нет фокуса/возврата фокуса для модалки.
- Лишние глобальные CSS override ломают другие панели.
