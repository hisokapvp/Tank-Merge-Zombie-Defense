# UI Guidelines

## Modal padding standard

- Единый отступ модалок задаётся через CSS-переменную `--uiModalPad` в `style.css`:
  - `--uiModalPad: clamp(16px, 4vw, 50px);`
- Базовые контейнеры, использующие стандарт:
  - `.levelModal__panel`
  - `.modalHeader`
  - `.modalBody`
  - `.levelModal__panel.scModal`
  - `.levelModal__panel_boost .levelModal__contentWrap`
  - `#modsTankWallOverlay .levelModal__panel.scModal` через `--mods-sc-pad-x: var(--uiModalPad)`

## Поведение на узких экранах

- Благодаря `clamp(16px, 4vw, 50px)` отступ уменьшается примерно до диапазона `16–24px` на узких экранах.
- Это уменьшает риск горизонтального переполнения контента в модалках без отдельных media-query.

## Стены (вкладка Supercomputer -> Walls)

- Для превью-иконки уровня стены поддерживаются 2 формата в `assets/fence.json -> levels[]`:
  1. Через id общего фрейма:
     - `uiFrameId: "sideTop"` (fallback-совместимость)
  2. Через отдельную UI-конфигурацию уровня:
     - `uiIcon: { atlas: "...", frameId: "..." }`
     - `uiIcon: { atlas: "...", frame: { x, y, w, h } }`
- При наличии `uiIcon.frame` используются прямые координаты кадра.
- Если `uiIcon.frame` отсутствует, используется `uiIcon.frameId` / `uiFrameId` / fallback `sideTop`.

## Дроны (вкладка Supercomputer -> Drones)

- В `modsTankWall` добавлена вкладка `Дроны` после `Орудия`.
- Таблица следует тому же паттерну, что `Орудия`/`Стены`, но с порядком колонок `Ур.` слева.
- Статы по уровням берутся из `assets/dron.json` (`levels[level].moveSpeedPxSec`, `repairSpeedMult`).
- Дополнительная колонка `Множитель стоимости ремонта` берётся из `assets/dron.json` (`levels[level].costMult`).
- При `+/-` в строке используется preview с учётом pending-апгрейда: отображается `base / upgraded` для `moveSpeedPxSec`, `repairSpeedMult`, `costMult` (без создания «новых дронов» в UI).
- Иконки дронов в строках используют fly-анимацию из `assets/dron.json -> animations.fly` (fallback: `animations.repair`, затем `animations.idle`).

## Wasteland UI (Fallout Style)

С 26.02.2026 интерфейс переведён на ретро-футуристический стиль.

### Цветовая палитра
- **Фон (Panel):** `#1a1a1a` / `#1e231e`
- **Текст (Phosphor):** `#4af626`
- **Акценты:** `#00ff00`
- **Тени:** Глубокие чёрные, 2px смещение для кнопок.

### Визуальные эффекты (CRT)
- **Scanlines:** Реализованы через `body::before` и псевдоэлементы панелей (`repeating-linear-gradient`).
- **Свечение:** Для текста и кнопок используется `text-shadow` и `box-shadow` в цвете фосфора.
- **Фильтр иконок:** `grayscale(1) invert(1) sepia(1) saturate(5) hue-rotate(70deg)` (окрашивание в зелёный).

### Кнопки
- Прямоугольные (`border-radius: 0`).
- Граница: `3px double` или `solid` цвета ржавого металла/темного оливкового.
- Минимум 1px сдвиг при `:active`.

### Шрифты
- Строго моноширинные: `'Courier New', Courier, monospace`.

## Треугольные чипы ангара (Supercomputer → Модификации ангара)

### Вкладки
- «Улучшение ячеек» — основная вкладка с системой треугольных чипов.
- «Мастерская» — вкладка с тремя подвкладками:
  - «Улучшение чипов» — сетка чипов с drag-and-drop слиянием.
  - «Открытие технологий» — дерево технологий с таймерами обучения.
  - «Создание чипов» — разборка целых чипов на фрагменты и сборка фрагментов в чипы.

### Инвентарь чипов
- Чипы **не стэкаются**: каждый чип — отдельная запись с `count: 1`.
- Слияние доступно через drag-and-drop при наличии 2+ одинаковых чипов (одинаковый `chipId` и `level`).
- При слиянии две записи удаляются и создаётся одна с `level + 1`.

### Инвентарь фрагментов
- Фрагменты хранятся как `[{ fragmentId (=modId), count }]`.
- Каждый из 30 модификаторов (1–30) может быть фрагментом.
- Фрагменты **стэкаются** по `fragmentId`.
- Визуальная форма: маленький треугольник вершиной вверх (SVG `_fragmentSvgUp()`).
- Фрагменты видны во вкладке «Создание чипов» и в модалке «Ускорить процесс обучения».

### Вкладка «Создание чипов»
- **Переключение режимов**: два toggle-кнопки «Разобрать» и «Создать чип» (`chipCraftModeBtn`). Активный режим подсвечен зелёным. По умолчанию — «Создать чип».
- **Лейаут**: верхняя панель (кнопка «Распылить» + ресурс кремниевой пыли), toggle-кнопки режимов, слева — инвентарь чипов/фрагментов, справа — зона предпросмотра (drop zone) с 3 слотами и кнопкой действия.
- **Разборка**: в режиме «Разобрать» кликабельны только целые чипы → чип помещается в слот 0 → кнопка «Разобрать» → чип удаляется, 3 фрагмента добавляются в инвентарь.
- **Сборка**: в режиме «Создать чип» кликабельны только фрагменты → 3 фрагмента заполняют слоты → кнопка «Создать чип» → фрагменты удаляются, новый чип уровня 1 добавляется. Валидация: запрещены 3 одинаковых модификатора, максимум 1 спец-мод (10–14).
- **Распылить (Dust mode)**: кнопка в верхней панели. При нажатии: drop-зона скрывается, на всех элементах инвентаря появляются чекбоксы. Большой чип = 10 ед. кремниевой пыли, фрагмент = 3 ед. Отображается динамический счётчик «Получите кремниевой пыли: X». Кнопки «Подтвердить» / «Отменить». Подтверждение: выбранные элементы уничтожаются, `_siliconDust` увеличивается.
- **Кремниевая пыль** (`_siliconDust`): новый ресурс, отображаемый в верхней панели. Сохраняется через `getSiliconDust()`/`setSiliconDust()`.

### Визуализация чипов
- **Composed SVG**: функция `chipSvgComposed()` рисует чип как большой контурный треугольник с 3 вложенными мини-треугольниками (по модификаторам). Используется везде: инвентарь, грид улучшений, craft panel, tech modal.
- **Зелёная подсветка match**: чипы в инвентаре, которые при установке создадут match с уже установленным красным чипом, подсвечиваются зелёным (`hangarChipBtn--canMatch`).
- **Drag-and-drop в слоты**: чип можно перетащить из инвентаря прямо в слот SVG-бабочки. При совпадении цвета чип устанавливается; если слот занят, старый чип возвращается в инвентарь.

### Система технологий (Tech Tree)
- **Тир 1** (заменяет base mod 1–14): длительность обучения **2 часа** (7200с). Каждый сожжённый чип = **+5%** ускорения. Каждый сожжённый фрагмент = **+2.5%**.
- **Тир 2** (заменяет tier-1 tech 15+): длительность обучения **5 часов** (18000с). Каждый сожжённый чип = **+2.5%** ускорения. Каждый сожжённый фрагмент = **+1.25%**.
- Длительность обучения **фиксирована** и определяется тиром, не зависит от разблокировки пререквизита.
- Максимальное ускорение: **95%**. При достижении кнопка «Ускорить» и сжигание чипов/фрагментов заблокированы. Также чекбоксы незаблокированных элементов визуально деактивируются (opacity + pointerEvents) для наглядности.
- Модалка «Ускорить процесс обучения» показывает и целые чипы, и фрагменты. Фрагменты отображаются в отдельном блоке с пояснением размера ускорения.
- Ускорение реализовано как **множитель скорости тика** (`1 / (1 - accelPct / 100)`), а не сокращение времени. Отображается полное оставшееся время, но секунды проходят быстрее.
- Таймер обучения ставится на паузу **только** при открытии настроек (маленькое меню) или большого меню. Во всех остальных оверлеях таймер продолжает тикать.
- **Таймер тикает плавно** (интервал 250мс с delta через `Date.now()`), показывая обратный отсчёт 60→59→58... без скачков при ускорении.
- **Ширина текста таймера фиксирована**: CSS-класс `.techUnlockCard__progressText--fixed` обеспечивает `min-width: 90px`, `text-align: right`, `font-variant-numeric: tabular-nums` — прогресс-бар не «прыгает» при смене количества цифр.

### Применение технологий
- При разблокировке технологии все чипы с заменяемым `modId` обновляются (и в инвентаре, и в установленных слотах).
- При установке чипа в слот используются `modIds` **из инвентарной записи** (а не из оригинального chipDef), что гарантирует применение разблокированных технологий.
- При снятии чипа со слота он возвращается в инвентарь с текущими (возможно обновлёнными) `modIds`.

### Лейаут
- Слева: сетка ячеек 4×4 (200px), каждая ячейка 46×46px.
- Справа: detail-панель (`stageUiRight`) расширена до `max-width: 550px` для лучшей вместимости элементов управления.
- Центральный элемент: SVG-бабочка (viewBox 400×300), повернутая на 90 градусов (`transform: rotate(90deg)`).
- Струткура слоев: Основное окно модалки `overflow: hidden`.

### SVG-бабочка и слоты
- 2 красных треугольника (ромб по центру) + 4 жёлтых угловых треугольника.
- **Геометрия**: Размер слотов уменьшен в 1.5 раза (scale 0.667). Зазор между слотами **постоянный**: `GAP_DEFAULT`. При совпадении чипов (match success) слоты не меняют размер, а **смещаются** (translate) друг к другу, закрывая зазор. Логика смещения:
  - **Red-Red**: красный слот смещается по горизонтали к соседнему красному.
  - **Yellow-Red**: активный жёлтый слот смещается к центроиду соседнего красного.
- **Текстовые метки**: Внутри SVG повернуты на -90 градусов для компенсации поворота контейнера.
- **Тултип слота**: При наведении на установленный чип в SVG-треугольнике показывается всплывающая подсказка с именем мода, типом чипа и уровнем. Тултип следует за курсором. Функции: `_showSlotChipTooltip()`, `_hideSlotChipTooltip()`.
- **Эфект дрожания**: Активные ("работающие") чипы используют анимацию `slotShake`.
  - Красный чип имеет статус "working" и дрожит всегда при установке в слот.
  - Желтый чип дрожит при `yellowMatchSuccess: true` (если выбран активным).
  - Анимация теперь более агрессивная (0.15s) и асинхронная (индивидуальный `animation-delay` для каждого слота).

### Фильтрация и список чипов
- Кнопки фильтра: «Все» / «Красные» / «Жёлтые».
- Список доступных чипов (`.hangarChipsGrid`): отображает только чипы из инвентаря игрока. Имеет фиксированный размер, вертикальный скролл и **отступ margin: 1px**, чтобы контент не перекрывал рамку.
- Чипы имеют фиксированный размер (`flex-grow: 0; flex-shrink: 0`), чтобы предотвратить растягивание при малом количестве элементов.
- `.hangarDetail` и `.hangarChipsList` используют `overflow: hidden` и `min-height: 0` для корректного ограничения списка чипов в flex-контейнере. `.hangarChipsGrid` имеет `max-height: 280px` и `overflow-y: auto`.
- Каждый чип отображается как кнопка 58px с миниатюрной SVG-иконкой и бейджем уровня (`.hangarChipBtn__lvl`).
- При установке чипа в слот он удаляется из инвентаря; при снятии — возвращается.
- **Бонус атаки** от уровня чипа начинается с уровня 2 (формула: `Math.max(0, (level - 1) * 10)`). Чип 1-го уровня даёт 0% бонус.

### Стили
- Фосфорная палитра Wasteland: зелёные акценты `#4af626`, тёмные фоны `#181818`/`#222`.
- Красные слоты: `rgba(229,57,53,0.18)` / stroke `#e53935`.
- Желтые слоты: `rgba(253,216,53,0.18)` / stroke `#fdd835`.
- Match-статус: зелёный при совпадении, оранжевый при отсутствии.

### Debug
- В debug panel (`?debug=1`) вкладка `Chips` для прямого управления чипами.
- Во вкладке `Updates` добавлена секция **«Learn Technology»**: выпадающий список всех технологий из `TECH_TREE` с возможностью мгновенной разблокировки выбранной технологии (обход таймера и пререквизитов). Уже изученные технологии помечены `[DONE]`.
