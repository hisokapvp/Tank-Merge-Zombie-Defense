# UI Guidelines

## Modal padding standard

- Единый отступ модалок задаётся через CSS-переменную `--uiModalPad` в `style.css`:
  - `--uiModalPad: clamp(16px, 4vw, 50px);`
- Базовые контейнеры, использующие стандарт:
  - `.levelModal__panel`
  - `.modalHeader`
  - `.modalBody`
  - `.levelModal__panel.scModal`
  - `.levelModal__panel_boost .levelModal__contentWrap`
  - `#modsTankWallOverlay .levelModal__panel.scModal` через `--mods-sc-pad-x: var(--uiModalPad)`

## Поведение на узких экранах

- Благодаря `clamp(16px, 4vw, 50px)` отступ уменьшается примерно до диапазона `16–24px` на узких экранах.
- Это уменьшает риск горизонтального переполнения контента в модалках без отдельных media-query.

## Стены (вкладка Supercomputer -> Walls)

- Для превью-иконки уровня стены поддерживаются 2 формата в `assets/fence.json -> levels[]`:
  1. Через id общего фрейма:
     - `uiFrameId: "sideTop"` (fallback-совместимость)
  2. Через отдельную UI-конфигурацию уровня:
     - `uiIcon: { atlas: "...", frameId: "..." }`
     - `uiIcon: { atlas: "...", frame: { x, y, w, h } }`
- При наличии `uiIcon.frame` используются прямые координаты кадра.
- Если `uiIcon.frame` отсутствует, используется `uiIcon.frameId` / `uiFrameId` / fallback `sideTop`.

## Дроны (вкладка Supercomputer -> Drones)

- В `modsTankWall` добавлена вкладка `Дроны` после `Орудия`.
- Таблица следует тому же паттерну, что `Орудия`/`Стены`, но с порядком колонок `Ур.` слева.
- Статы по уровням берутся из `assets/dron.json` (`levels[level].moveSpeedPxSec`, `repairSpeedMult`).
- Дополнительная колонка `Множитель стоимости ремонта` берётся из `assets/dron.json` (`levels[level].costMult`).
- При `+/-` в строке используется preview с учётом pending-апгрейда: отображается `base / upgraded` для `moveSpeedPxSec`, `repairSpeedMult`, `costMult` (без создания «новых дронов» в UI).
- Иконки дронов в строках используют fly-анимацию из `assets/dron.json -> animations.fly` (fallback: `animations.repair`, затем `animations.idle`).

## Wasteland UI (Fallout Style)

С 26.02.2026 интерфейс переведён на ретро-футуристический стиль.

### Цветовая палитра
- **Фон (Panel):** `#1a1a1a` / `#1e231e`
- **Текст (Phosphor):** `#4af626`
- **Акценты:** `#00ff00`
- **Тени:** Глубокие чёрные, 2px смещение для кнопок.

### Визуальные эффекты (CRT)
- **Scanlines:** Реализованы через `body::before` и псевдоэлементы панелей (`repeating-linear-gradient`).
- **Свечение:** Для текста и кнопок используется `text-shadow` и `box-shadow` в цвете фосфора.
- **Фильтр иконок:** `grayscale(1) invert(1) sepia(1) saturate(5) hue-rotate(70deg)` (окрашивание в зелёный).

### Кнопки
- Прямоугольные (`border-radius: 0`).
- Граница: `3px double` или `solid` цвета ржавого металла/темного оливкового.
- Минимум 1px сдвиг при `:active`.

### Шрифты
- Строго моноширинные: `'Courier New', Courier, monospace`.

## Треугольные чипы ангара (Supercomputer → Модификации ангара)

### Вкладки
- «Улучшение ячеек» — основная вкладка с системой треугольных чипов.
- «Мастерская» — заглушка «В разработке».

### Лейаут
- Слева: сетка ячеек 4×4 (200px), каждая ячейка 46×46px.
- Справа: detail-панель (`stageUiRight`) расширена до `max-width: 550px` для лучшей вместимости элементов управления.
- Центральный элемент: SVG-бабочка (viewBox 400×300), повернутая на 90 градусов (`transform: rotate(90deg)`).
- Струткура слоев: Основное окно модалки `overflow: hidden`.

### SVG-бабочка и слоты
- 2 красных треугольника (ромб по центру) + 4 жёлтых угловых треугольника.
- **Геометрия**: Размер слотов уменьшен в 1.5 раза (scale 0.667), а зазор между ними увеличен до `GAP = 10px` для лучшей визуальной сепарации.
- **Текстовые метки**: Внутри SVG повернуты на -90 градусов для компенсации поворота контейнера.
- **Эфект дрожания**: Активные ("работающие") чипы используют анимацию `slotShake`. 
  - Красный чип имеет статус "working" и дрожит всегда при установке в слот.
  - Желтый чип дрожит при `yellowMatchSuccess: true` (если выбран активным).
  - Анимация теперь более агрессивная (0.15s) и асинхронная (индивидуальный `animation-delay` для каждого слота).

### Фильтрация и список чипов
- Кнопки фильтра: «Все» / «Красные» / «Жёлтые».
- Список доступных чипов (`.hangarChipsGrid`): теперь имеет фиксированный размер внутри правой панели с поддержкой вертикального скролла (`overflow-y: auto`).
- Каждый чип отображается как кнопка 58px с миниатюрной SVG-иконкой.

### Стили
- Фосфорная палитра Wasteland: зелёные акценты `#4af626`, тёмные фоны `#181818`/`#222`.
- Красные слоты: `rgba(229,57,53,0.18)` / stroke `#e53935`.
- Желтые слоты: `rgba(253,216,53,0.18)` / stroke `#fdd835`.
- Match-статус: зелёный при совпадении, оранжевый при отсутствии.

### Debug
- В debug panel (`?debug=1`) вкладка `Chips` для прямого управления чипами.
