# tanks.json  краткий контракт

## Назначение
Описывает уровни танков, их визуальные части и связанные параметры.

## Обязательное
- Стабильные идентификаторы уровней (`tank_lvlN`).
- Поля, которые читает рендер (`frame`, `anchor`, пути к спрайтам).

## Правило
При добавлении уровня синхронно проверить рендер, merge и магазин.
