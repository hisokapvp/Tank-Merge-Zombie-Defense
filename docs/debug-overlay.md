# Debug overlay: zombie attack targets

## Условия включения

- Overlay существует только в debug-режиме: URL должен содержать `?debug=1`.
- Toggle во время игры: клавиша `H`.

## Что рисуется

- `AABB` всех fence-сегментов (`side` + `corner`).
- Для каждого живого зомби:
  - круг радиуса `attackRangePx` вокруг `zombieCenter`,
  - маркер текущей выбранной цели,
  - линия от зомби до выбранного сегмента.

## Производительность

- Когда overlay выключен, дополнительных проходов рендера нет.
- Логика overlay не влияет на обычный gameplay-render path.

## Назначение

Overlay нужен для визуальной отладки:

- правильного выбора цели около corner-сегментов,
- соблюдения дистанции `attackRangePx`,
- стабильности tie-break при быстрых сменах целей.
