Сделать что-то вроде производственной линии слева от спрайта суперкомпьютера, которая будет состоять из двух частей. Первая часть это конвейер (нужна возможность установить какой-то атлас спрайтов для этого элемента, сейчас сделать заглушку), который будет прокручивать какую-то анимацию движения и по ней будет медленно ехать спрайт коробки (нужна возможность установить какой-то атлас спрайтов для этого элемента, сейчас сделать заглушку), который будет медленно печататься, примерно по такому же принципу как сейчас печатаются танки. Вторая часть это что-то вроде ячейки-склада (нужна возможность установить какой-то атлас спрайтов для этого элемента, сейчас сделать заглушку), в которую будут помещаться коробки, которые будут напечатаны на конвейере.

Конвейер не интерактивный элемент для игрока. Фактически это просто визуальное отображение появления коробки в ячейке-склада. Процесс появления коробки завязан на количестве убийств зомби. Например для первой коробки нужно будет убить 500 зомби, для второй коробки 1000 зомби, для третей коробки 2000 зомби и так, пока количество зомби требуемое для появления коробки не достигнет например 50 000, в этот момент рост цены коробки должен будет прекратится. Получается конвейер работает всегда и всегда показывает анимацию, но коробка печатается в зависимости от того сколько убито зомби и с такой же скоростью эта коробка двигается от начала конвейера к ячейке-складу.

Ячейка-склад это интерактивный элемент при нажатии на который открывается модалка с ячейками, в каждой ячейке находится одна коробка. Количество возможных ячеек не ограничено, но по умолчанию их например 9 штук (3х3). В этой модалке должна быть кнопка Х чтобы закрыть окно. Если игрок тыкает по ячейке с коробкой, то выскакивает сообщение Хотите открыть коробку? и кнопки Да и Нет.

При открытии коробки игрок может получить: Дрон (самый маленький шанс), два случайных больших чипа (самый маленький шанс), один случайный большой чип (маленький шанс), три случайных фрагмента чипа (маленький шанс), два случайных фрагмента чипа (средний шанс), 10 единиц кремниевой пыли (средний шанс), один случайный фрагмент чипа (большой шанс), 5 единиц кремниевой пыли (большой шанс).
