# Rendering Pipeline

## Fence HP bars layer order

Текущий порядок ключевых слоёв в кадре:

1. `renderFenceBase()` — база стен и их декор (без HP-баров)
2. `renderZombiesAndCorpses()` — зомби и трупы
3. `renderFenceHpBars()` — только HP-бары сегментов стен
4. `renderProjectilesAndEffects()` — снаряды и визуальные эффекты

## Почему так

- HP-бары стен остаются читаемыми поверх плотной группы зомби/трупов.
- Снаряды/взрывы/прочие эффекты могут перекрывать HP-бары — это допускается как FX-слой выше UI-индикаторов мира.

## Производительность

- Тяжёлые расчёты геометрии/пересборки fence-сегментов выполняются в base-pass.
- `renderFenceHpBars()` использует уже подготовленные сегменты и не дублирует тяжёлую подготовку.

## Live-update tier стен

- Tier стен синхронизируется с максимальным достигнутым уровнем танка (`maxTankLevelAchieved` + runtime marker).
- Применение выполняется один раз на изменение tier:
  - обновляется `state.fenceLevel`
  - сбрасывается кэш сегментов для одноразовой перестройки
  - выполняется `FenceSprites.ensureLevel(...)` для hot-refresh атласа
- Обновление не зависит от popup-события level up и работает в текущей симуляции, включая повторные прогоны.

## UI Geometry: Hangar Triangular Chips

Для рендеринга треугольных слоев в ангаре используется SVG-система:
- **Gapped Triangles & Attraction**: Функция `getGappedPoints` вычисляет вершины треугольников с фиксированным отступом `GAP = 10px`. 
  - При совпадении цветов слоты не увеличиваются, а **смещаются** (`tx, ty`) друг к другу (attraction logic), закрывая зазор. Это обеспечивает стабильный размер элементов.
- **Rotation Offset**: Основной SVG-контейнер `.hangarSvg` имеет `transform: rotate(90deg)`. Для сохранения читаемости текстовых меток (`text`) внутри SVG применяется компенсационный поворот на `-90deg`.
- **Animations**: Эффект "дрожания" для активных чипов реализован через CSS-анимацию `slotShake` (небольшие смещения и поворот), которая применяется к группе элементов текста и иконок внутри слота. Анимация стала более агрессивной (0.15s) и асинхронной для каждого слота (animation-delay).
- **Scale**: Геометрия треугольных слотов уменьшена в 1.5 раза (масштаб 0.667) относительно базового дизайна для размещения в обновленном интерфейсе.
