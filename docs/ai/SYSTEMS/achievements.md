# Система: Achievements

## Где править
- Логика: `src/mechanics/achievements.js`
- UI: `src/ui/*` (экраны достижений)

## UI-поведение модалки достижений
- Список достижений работает как accordion single-open: одновременно раскрыто только одно достижение.
- Toggle-кнопка показывает `+` для закрытого и `−` для открытого состояния.
- Повторный клик по открытому достижению закрывает его.
- При каждом открытии `achievementsModal` все достижения стартуют закрытыми.
- Для кликов по toggle используется event delegation на контейнере списка.
- Полученные достижения имеют явный done-state в списке: усиленный фон/рамка строки + бейдж статуса в header.
- Контейнер списка `achievementsList` использует унифицированный styled scrollbar (как у других UI-модалок/аудио), без отдельного нестандартного визуального паттерна.

## Правила
- Пороги и unlock-условия менять консистентно для веток `creator_*` и `engineer_*`.
- Сохранять совместимость старых сейвов (миграция ключей/структуры при необходимости).
- Не смешивать debug-операции с обычным gameplay.
