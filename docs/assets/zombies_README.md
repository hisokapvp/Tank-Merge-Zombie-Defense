# zombies.json  краткий контракт

## Назначение
Описывает типы зомби, их параметры движения/атаки и death-анимации.

## Обязательное
- Уникальные `type/id`.
- Согласованность скоростей, HP, cooldown и конфигов анимации.

## Правило
Любое изменение параметров валидировать в `zombieSpawn`, target selection и attack flow.
