# zombies.json — настройка зомби и death-анимаций

Файл `zombies.json` задаёт внешний вид и поведение зомби, включая анимации смерти.

---

## Структура файла

### 1. Атлас (`atlas`)

Путь к PNG-файлу атласа относительно папки `assets/`:

```json
"atlas": "zombie_atlas.png"
```

---

### 2. Общая death-анимация (`deathCommon`)

Анимация смерти, используемая для всех типов зомби как fallback или случайный выбор (30% шанс, если есть персональная анимация):

```json
"deathCommon": {
  "x": 0,       // X-координата первого кадра на атласе (пиксели)
  "y": 384,     // Y-координата первого кадра на атласе (пиксели)
  "w": 96,      // Ширина одного кадра (пиксели)
  "h": 96,      // Высота одного кадра (пиксели)
  "frames": 8   // Количество кадров анимации (расположены в ряд)
}
```

**Схема «в ряд»**: кадры располагаются горизонтально друг за другом. Кадр 0 находится в `(x, y)`, кадр 1 в `(x + w, y)`, кадр 2 в `(x + 2*w, y)` и т.д.

---

### 2.5. Спавн-конфиг (`spawn`)

Data-driven лимиты alive-зомби и баланс по сторонам кольца:

```json
"spawn": {
  "targetAlive": 240,
  "sideCount": 4,
  "perSideTarget": 60,
  "perSideTolerance": 5
}
```

| Поле | Описание |
|------|----------|
| `targetAlive` | Целевой alive-cap (сколько одновременно живых зомби поддерживает `ensureZombieCount`) |
| `sideCount` | Количество сторон для балансировки (обычно 4) |
| `perSideTarget` | Цель по alive на одну сторону |
| `perSideTolerance` | Допуск отклонения от `perSideTarget` |

Рекомендуемая настройка для текущего баланса: `240` total и `~60` на сторону (`±5`).

---

### 3. Типы зомби (`types`)

Массив объектов, каждый описывает один тип зомби:

| Поле        | Описание                                                  |
|-------------|-----------------------------------------------------------|
| **id**      | Уникальный идентификатор (например `zombie_lvl1`)         |
| **frame**   | Координаты walk-анимации: `{ x, y, w, h }`                |
| **frames**  | Количество кадров walk-анимации                           |
| **death**   | *(опционально)* Персональная death-анимация               |
| **anchor**  | Точка привязки спрайта: `{ x: 0.5, y: 0.75 }`            |
| **scale**   | Масштаб спрайта (обычно 0.7)                              |
| **hpMul**   | Множитель HP                                              |
| **omegaMul**| Множитель скорости вращения                               |
| **rewardMul**| Множитель награды за убийство                            |
| **weight**  | Вес для случайного выбора типа                            |
| **hitbox**  | Хитбокс: `{ r: 18 }` — радиус                             |

---

### 4. Персональная death-анимация (`death`)

Добавляется внутрь объекта типа зомби. Формат аналогичен `deathCommon`:

```json
{
  "id": "zombie_lvl1",
  "frame": { "x": 0, "y": 0, "w": 96, "h": 96 },
  "frames": 10,
  "death": {
    "x": 960,     // X-координата первого кадра death-анимации
    "y": 0,       // Y-координата (обычно та же строка, что и walk)
    "w": 96,      // Ширина кадра
    "h": 96,      // Высота кадра
    "frames": 6   // Количество кадров death-анимации
  },
  "anchor": { "x": 0.5, "y": 0.75 },
  "scale": 0.7,
  ...
}
```

---

## Логика выбора death-анимации

При смерти зомби выбирается одна из анимаций:

| Ситуация                              | Что используется          |
|---------------------------------------|---------------------------|
| Есть `death` и `deathCommon`          | 70% — персональная, 30% — общая |
| Только `death`                        | 100% — персональная       |
| Только `deathCommon`                  | 100% — общая              |
| Ни того, ни другого                   | Fallback: fade + tilt     |

Анимация проигрывается **non-loop** (останавливается на последнем кадре).

## Как добавить death-анимацию

### Шаг 1: Подготовить спрайты

Нарисуйте кадры death-анимации и расположите их **в ряд** на `zombie_atlas.png`.

Пример: 6 кадров размером 96×96 начиная с позиции (960, 0):
- Кадр 0: (960, 0)
- Кадр 1: (1056, 0)
- Кадр 2: (1152, 0)
- ...

### Шаг 2: Добавить `deathCommon` (общая для всех)

В корне `zombies.json` добавьте:

```json
{
  "atlas": "zombie_atlas.png",
  "deathCommon": {
    "x": 0,
    "y": 384,
    "w": 96,
    "h": 96,
    "frames": 8
  },
  "types": [...]
}
```

### Шаг 3: Добавить персональную `death` (для конкретного типа)

Внутри нужного типа в массиве `types` добавьте поле `death`:

```json
{
  "id": "zombie_lvl1",
  "frame": { "x": 0, "y": 0, "w": 96, "h": 96 },
  "frames": 10,
  "death": {
    "x": 960,
    "y": 0,
    "w": 96,
    "h": 96,
    "frames": 6
  },
  ...
}
```

## Пример полной конфигурации

```json
{
  "atlas": "zombie_atlas.png",
  "deathCommon": {
    "x": 0,
    "y": 384,
    "w": 96,
    "h": 96,
    "frames": 8
  },
  "types": [
    {
      "id": "zombie_lvl1",
      "frame": { "x": 0, "y": 0, "w": 96, "h": 96 },
      "frames": 10,
      "death": {
        "x": 960, "y": 0, "w": 96, "h": 96, "frames": 6
      },
      "anchor": { "x": 0.5, "y": 0.75 },
      "scale": 0.7,
      "hpMul": 1,
      "omegaMul": 1,
      "rewardMul": 1,
      "weight": 1,
      "hitbox": { "r": 18 }
    },
    {
      "id": "zombie_lvl2",
      "frame": { "x": 0, "y": 96, "w": 96, "h": 96 },
      "frames": 8,
      "anchor": { "x": 0.5, "y": 0.75 },
      "scale": 0.7,
      "hpMul": 1,
      "omegaMul": 1,
      "rewardMul": 1,
      "weight": 1,
      "hitbox": { "r": 18 }
    }

```

В этом примере:
- `zombie_lvl1` имеет персональную death-анимацию
- `zombie_lvl2` использует только `deathCommon`

## Edge cases и обработка ошибок

| Ситуация                                | Поведение                           |
|-----------------------------------------|-------------------------------------|
| Неверные координаты (x, y за пределами) | Рисуется пустая область (без краша) |
| `frames: 0` или отсутствует             | Используется 1 кадр                 |
| Отсутствует `deathCommon` и `death`     | Fallback на fade + tilt эффект      |
| Атлас не загружен                       | Зомби рисуется как fallback-круг    |

## Параметры анимации

| Параметр           | Значение по умолчанию | Описание                        |
|--------------------|-----------------------|---------------------------------|
| `deathAnimSpeed`   | 10 fps                | Скорость проигрывания (в коде)  |
| `deathDuration`    | 0.65 сек              | Общая длительность умирания     |
| Fade alpha         | 0→50% при death anim  | Прозрачность при умирании       |
