# Инструкция по откату

## Когда откатывать
- Провалены проверки целостности или критичные smoke-тесты.
- Зафиксирована деградация core-геймплея/сейвов/монетизации.

## Шаги
1. Остановить выкладку текущего артефакта.
2. Вернуть последний стабильный релиз.
3. Запустить `bash ops/release/post_release_checks.sh`.
4. Проверить сохранность пользовательских данных.
5. Зафиксировать причину и план исправления.
