# Стиль кода

## JavaScript
- `const/let`, короткие функции, явные имена.
- Не добавлять тяжёлые аллокации в hot path (`loop`, `draw`, `step*`).
- Пользовательские строки  только через `i18n`.

## HTML/CSS
- Семантическая разметка, интерактивы через `button`.
- Для модалок обязательны `role="dialog"` и `aria-modal="true"`.
- Не добавлять глобальные CSS override без необходимости.

## Проверки
- Тесты детерминированные, без скрытых побочных эффектов.
- Перед PR запускать `check_style` и `run_tests`.
