# UI Shop: bulk-покупка танков

## Правило количества

- Количество для bulk-покупки рассчитывается динамически:
  - `X = min(5, freeSlots)`
- Для текста кнопки используется диапазон `2..5`:
  - при `freeSlots < 2` кнопка показывает `2`, но остаётся disabled

## Состояние кнопки

- Кнопка bulk-покупки видима всегда.
- Кнопка disabled, если:
  - `freeSlots < 2`, или
  - не хватает денег на покупку ровно `X` танков

## Поведение по клику

- Если кнопка disabled/условия не выполнены — no-op.
- Если условия выполнены — покупается ровно `X` танков.
- Стоимость списывается по текущей игровой формуле за каждый танк (эквивалентно `pricePerTank` с динамикой цены), суммарно за `X`.
- Частичная bulk-покупка не допускается: операция должна быть доступна только когда бюджет хватает на полный `X`.
