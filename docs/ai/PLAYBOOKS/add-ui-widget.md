# Плейбук: Добавить UI-виджет

## Шаги
1. Добавить разметку в `index.html`.
2. Добавить стили в `style.css` без новых глобальных override.
3. Логику вынести в `src/ui/<widget>.js`.
4. Подключить скрипт перед `game.js`.
5. Добавить RU/EN ключи в `src/i18n/*`.
6. Для модалки подключить `Game.A11y`.

## Проверка
- Клик и клавиатура работают.
- RU/EN переключается корректно.
- Escape/Tab корректны для модалки.
