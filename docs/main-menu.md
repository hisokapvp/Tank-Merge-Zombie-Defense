# Главное меню (big menu)

## Когда показывается

- При открытии страницы сначала показывается отдельный full-screen overlay `#bigMenuOverlay`.
- До выбора действия из big menu игра не запускает `boot()` и не запускает `loop()`.

## Кнопки (порядок фиксированный)

1. `#bigMenuNew` — **Новая игра**
   - Запускает boot.
   - После boot сразу выполняет reset в режим новой игры.
   - In-session меню закрывается (`setMenuOpen(false)`), игрок сразу попадает в сессию.
2. `#bigMenuLoad` — **Загрузить**
   - Запускает boot.
   - Загружает прогресс из `localStorage['progress']` через обычный runtime-пайплайн загрузки.
   - In-session меню закрывается (`setMenuOpen(false)`), игрок сразу попадает в сессию.
3. `#bigMenuSound` — **Звук**
   - Открывает простую вложенную панель со слайдерами SFX/Music.
4. `#bigMenuLanguage` — **Язык**
   - Открывает простую вложенную панель выбора `РУ/EN`.
   - Выбор языка вызывает глобальный setter `setLanguage(...)` и обновляет видимые тексты big menu в рантайме без reload.
   - Источник истины языка — `localStorage['lang']`.
5. `#bigMenuFeedback` — **Обратная связь**
   - Пробует программно кликнуть `#feedbackBtn` (если существует), иначе вызывает `Game.FeedbackWidget.open()`.
6. `#bigMenuDevs` — **Devs**
   - Открывает простую dev-панель внутри big menu.

## Логика `Загрузить`

- Проверка делается по `getSavedProgress()` (источник — `localStorage['progress']`/Storage API).
- Если сохранения нет:
  - `#bigMenuLoad` переводится в `disabled`;
  - показывается подсказка с текстом: **«Нет сохранения»**;
  - у кнопки выставляется `title="Нет сохранения"`.
- Если сохранение есть:
  - кнопка `#bigMenuLoad` активна;
  - подсказка скрыта.

## Язык и порядок инициализации

- Ключ языка: `localStorage['lang']`.
- Порядок init для big menu: `прочитать lang -> setLanguage(lang|default) -> renderBigMenuTexts() -> показать overlay`.
- Быстрое переключение `РУ/EN` поддерживается через единый рендер всех видимых текстов big menu (без смешивания строк из разных языков).

## In-session small menu (`#menuOverlay`)

- В small menu больше **нет переключателя языка** (язык настраивается только в big menu).
- Кнопки действий: `Продолжить`, `Новая игра`, `Сохранить`, `Обратная связь`, `Выход`.
- `Выход` всегда последняя кнопка (ниже `Обратная связь`).

### `Сохранить`

- Открывает `SaveSlotsList` со слотами `1..10`.
- Клик по слоту открывает `SaveSlotEdit(i)` с полем имени и кнопками `Сохранить / Назад / Закрыть`.
- Хранится только метадата имени слота в `localStorage['saveSlotsMeta_v1']`.
- Формат: `{ slots: [{ name: string }, ... 10] }`.
- Правила имени:
   - `maxLen = 20`;
   - пустое/пробельное значение после `trim()` заменяется на default `Слот N`;
   - `Enter` в input = действие `Сохранить`, `Esc` = `Назад`.
- После сохранения показывается alert:
   - RU: `Игра успешно сохранена`
   - EN: `Game saved successfully`
- Сохранение прогресса в слот **не выполняется** (пока сохраняется только имя).

### `Выход`

- Открывает confirm `Выйти без сохранения?` с кнопками `Выйти / Отмена`.
- `Отмена` закрывает confirm и возвращает в main-view small menu.
- `Выйти` выполняет reset **без перезагрузки страницы**:
   - останавливаются активные runtime-циклы (main loop и трекаемые timer/RAF задачи);
   - закрываются open модалки/подменю и снимаются menu pause-lock источники;
   - выполняется reset runtime state до чистого состояния;
   - удаляется `localStorage['progress']`;
   - показывается `#bigMenuOverlay`.
- Не удаляются: `localStorage['lang']`, настройки звука, `localStorage['saveSlotsMeta_v1']`.

## Отличие от big menu

- Big menu — стартовый экран перед первым запуском boot/loop.
- In-session меню (`#menuOverlay`, gear/ESC) — меню паузы внутри активной сессии.
