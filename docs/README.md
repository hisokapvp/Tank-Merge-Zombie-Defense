# Документация проекта

## Быстрые ссылки
- Индекс для навигации: `docs/ai/INDEX.md`
- Архитектура: `docs/ai/ARCHITECTURE.md`
- Правила изменений: `docs/ai/STYLE.md`
- Системы: `docs/ai/SYSTEMS/*.md`
- Повторяемые процедуры: `docs/ai/PLAYBOOKS/*.md`

- Ассеты: `docs/assets/tanks_README.md`, `docs/assets/zombies_README.md`
